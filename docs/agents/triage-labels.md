# Triage labels

Vocabulary vendored skills expect when they publish to the tracker.

| Role | Label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | Maintainer needs to evaluate |
| needs-info | `needs-info` | Waiting on the reporter |
| ready-for-agent | `ready-for-agent` | Specified enough to compile an Arena Issue |
| ready-for-human | `ready-for-human` | Requires human implementation |
| wontfix | `wontfix` | Will not be actioned |

`ready-for-agent` is tracker readiness, not Arena dispatch.
